A QUICK START
From a molecule
to its electronic structure.
  1. Define the system. Choose an example, import an XYZ file, or edit coordinates. H₂⁺ and HeH examples load the appropriate UHF doublet settings.
  2. Choose the calculation. Set method, basis, charge and multiplicity. Run a single point or a bond-length scan.
  3. Inspect the result. Follow SCF convergence, compare spin orbitals and matrices, or select a point on a potential energy curve. Export numerical results as JSON or CSV.
⌘ Enter or Ctrl Enter runs a calculation. Esc closes this guide, the setup drawer, or the expanded viewer. Energies are in Hartree (Eₕ).
